### ⚡ How It Works

1. **Fetch**: Retrieves page with anti-detection browser
2. **Detect**: Automatically finds embedded JSON or analyzes HTML structure
3. **Analyze**: LLM-powered structure analysis (cached per domain+fields)
4. **Extract**: Semantic field mapping extracts requested data
5. **Cache**: Results cached for future requests (99% cost savings)
